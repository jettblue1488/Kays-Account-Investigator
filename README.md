# Kay's Account Investigator

Native Android starter app with red-and-black theme.

## Current functionality
- Import a locally selected .eml or .txt email file through Android's document picker.
- Scan for references to common social and dating platforms.
- Save the latest report locally.
- Build a debug APK with GitHub Actions.

## Important
This version **does not access logged-in Gmail, Yahoo or Outlook accounts**. Those require user-authorized provider integrations. A domain mention is not proof that an account exists or is currently active. No email is uploaded to a server.

Open **Actions > Build Android APK** to download the build artifact after a successful run.
